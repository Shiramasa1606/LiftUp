# Liftup

## Descripción
Liftup es una plataforma de e-commerce para donaciones desarrollada con Ionic React, diseñada para permitir a los usuarios crear y gestionar proyectos de recaudación de fondos. Los usuarios pueden donar a proyectos que les interesen, seguir iniciativas que les apasionen, y administrar su perfil y proyectos de manera intuitiva. Con Liftup, se facilita el proceso de recaudación de fondos, conectando a donantes con proyectos que buscan apoyo.

## Análisis de las Funcionalidades
- **Inicio de Sesión**: Permite a los usuarios acceder a su cuenta de manera segura.
- **Registro**: Los nuevos usuarios pueden crear una cuenta para empezar a utilizar la plataforma.
- **Recuperar Contraseña**: Los usuarios pueden restablecer su contraseña en caso de olvido.
- **Perfil de Usuario**: Cada usuario tiene un perfil personal donde puede ver y editar su información.
- **Modificar Perfil**: Los usuarios pueden actualizar sus datos personales y agregar detalles como una foto de perfil.
- **Crear Proyecto**: Los usuarios pueden iniciar nuevos proyectos de donación, definiendo objetivos y metas.
- **Modificar Proyecto**: Permite a los usuarios editar la información de sus proyectos existentes.
- **Donar a un Proyecto**: Facilita a los usuarios realizar donaciones a proyectos que les interesen.
- **Visualizar Mis Proyectos**: Los usuarios pueden ver y gestionar los proyectos que han creado.
- **Visualizar Proyectos Seguidos**: Los usuarios pueden consultar los proyectos que están siguiendo y apoyar activamente.

## Maquetación Responsiva
La aplicación está desarrollada con Ionic React, una tecnología que permite desarrollar aplicaciones con una experiencia nativa en dispositivos móviles. Utilizando componentes de Ionic y React, se garantiza una interfaz adaptativa y optimizada para diferentes tamaños de pantalla, manteniendo una experiencia de usuario consistente en dispositivos móviles, tabletas y escritorios.

## Tecnologías
- **Ionic React**: Framework principal de desarrollo para una experiencia móvil optimizada.
- **JavaScript**: Lógica de negocio y manejo de estados.
- **HTML5 y CSS3**: Estructura y estilos de la interfaz.
- **Figma**: Herramienta de diseño y prototipado.
